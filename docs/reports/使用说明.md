# 会议录音插件使用说明

在思源桌面端录会议、记笔记、回听、转写和整理纪要。支持平台为 Windows 11 和 macOS 27，要求思源 3.8.7 或以上版本，桌面和 iOS／Android 手机使用同一份插件包；手机提供查看、回听与已有录音导入。

## 安装与开始

1. 解压插件包，将内容放入测试工作空间的 `data/plugins/siyuan-meeting/`，然后在思源的插件设置中启用“会议录音”。更新后重新启用插件。
2. 点击右上角话筒图标，选择“新建会议”。新会议集中放在所选笔记本的「会议」目录下，没有该目录时自动创建。点击图标本身不会录音。
3. 在录音设置中选择麦克风。线下只录麦克风；线上同时录麦克风和电脑播放的声音。线上请戴耳机，避免重复录入外放声音。
4. 点击“开始录音”。会议刚开始没人说话或麦克风静音时也会正常录音，电脑声音长时间安静只作提示，不会自动停止。如果无法打开电脑声音，线上录音会提示处理，不会悄悄改成只录麦克风。
5. 暂停会停止采集，继续后仍是同一段；结束并保存后，可在原会议中补录，已有录音保留。

macOS 首次录音需要允许思源访问麦克风；线上录音还需要屏幕与系统音频录制权限。若系统拒绝，请在「系统设置 → 隐私与安全性」中检查思源对应的权限，授权后重新打开思源。系统授权成功仍需通过实际双方声音确认录制结果。

插件使用当前打开的思源工作空间。原有笔记和附件仍在该工作空间的 `data/`，安装插件不会搬动这些内容。若只看见测试笔记，请从思源的工作空间菜单打开原来的工作空间；不同工作空间的数据不会自动合并。

## 会议页与浮条

会议页可切换“纪要 / 笔记 / 转写”。标题默认使用会议创建时间，可以修改。笔记和纪要都是思源原生文档，可以直接编辑，也可以选择“在思源文档中打开”。

在会议笔记、纪要或转写的原生文档页，点击顶部右侧的「打开会议」可返回对应的插件会议页；已经打开的会议页会直接切换过去。

录音时，屏幕底部浮条显示时间和音量，可暂停、继续、结束或返回会议。Windows 上共享屏幕时其他参会者看不到浮条；macOS 上浮条会出现在共享画面中。切换文档或关闭会议页不会停止录音。录音及保存期间不提供回听；结束后在转写页选择录音段播放，点击时间戳跳到对应位置。

开始录音前，按钮旁会显示「线下会议」或「线上会议」，点击可切换并查看说明。线下会议录下你和身边人的声音；线上会议同时录下麦克风和电脑播放的声音，请使用耳机。麦克风设备可从「⋯ → 录音设置」选择或刷新，录音期间不可调整。悬停「开始录音／补录」可查看声音来源和当前麦克风。录音中，计时旁两条细音量条分别对应麦克风（主题色）和电脑声音（青色）。页头下方只在需要你处理时才出现提示。分屏时布局随会议页宽度调整。

录音持续保存在本机。思源意外退出后，可从提示中选择“保存已录部分”。休眠或退出期间不会继续录音。保存失败时请保留本机文件，按提示重试。

## 添加已有录音与手机使用

桌面会议页点击「添加已有录音」，选择 M4A、MP3 或 WAV，然后点击「添加到会议」。也可以先新建会议再导入。导入保留原文件，不自动转写或产生识别费用；录音尚未结束的会议需先结束录音。

iPhone「语音备忘录」中的录音，可先通过分享保存到「文件」，再在插件中选择导出的 `.m4a` 文件。无需手动改成 WAV，也不要只修改扩展名。导入时保持思源在前台；上传成功而归档失败时，提示会保留附件路径，可在当前窗口重试归档。

手机启用插件后，从思源主菜单「扩展」区域或「插件」菜单中的「会议」入口打开列表，选择已有会议或新建会议。顶部「笔记 / 转写 / 纪要」在同一会议页内切换，分别保留阅读位置，不中断回听；默认只读，需要编辑时点击「在原生文档中编辑」。录音区可展开或收起，提供导入和回听。手机不提供现场录音、云端转写和生成纪要。

将会议与附件同步到电脑后，在转写页选择导入录音并手动识别，随后可生成纪要。导入录音按原格式提交，文件超过豆包 512 MB／腾讯云 1 GB 或达到五小时时长时，需先分割后导入；已保存的原附件不删除。回听能力取决于设备是否支持文件中的音频编码。

## 会议目录与双向导航

新会议的结构为「会议目录 → 会议名称（笔记正文）→ 转写 / 纪要」，转写与纪要仍按实际需要创建。现有会议不自动搬动，也不会批量修改正文。

新建转写、纪要文档时，会在会议正文加入对应入口，并在子文档加入「返回会议」。这些入口使用思源原生块引用，标题或目录变更后仍按文档 ID 跳转，也可从原生反链查看关联。手机阅读区内点击同场会议的导航引用可直接切换对应标签。

导航块不参与会前笔记和 AI 纪要材料，重新生成纪要时保留返回链接。

## 配置转写

在「会议设置」选择豆包或腾讯云，实时与会后识别使用同一家。

- 豆包：填写 API Key，开通流式语音识别 2.0 和录音文件识别标准版 2.0。
- 腾讯云：填写 SecretId、SecretKey，开通实时语音识别及录音文件大模型 2.0。AppId 自动获取，无需填写；密钥需要语音识别和获取账号信息的权限。
- COS：与腾讯语音共用上述 SecretId、SecretKey。只需填写「COS 存储桶地址」，从控制台复制默认域名，例如 `https://meeting-1250000000.cos.ap-shanghai.myqcloud.com`。无需分别填写桶名、地域。

COS 密钥需要所选私有桶 `siyuan-meeting/` 目录的上传、下载和删除权限。即使选择豆包，会后识别也需要 COS。插件不内置任何个人凭据，密钥仅存本机；留空表示不修改，每台设备分别配置。

实时识别直接发送音频流。会后识别先上传临时录音至 COS，再通过限时链接供所选服务读取。转写文字成功保存后，插件删除本次任务创建的 COS 临时录音，思源原录音保留。清理失败会显示提示，可点击「重试清理云端录音」；重开对应会议也会继续清理。

线上会议的麦克风和电脑声音混成单声道识别，原录音仍保留双声道。字幕和转写不自动标注「我／其他参会者」：模型能区分说话人时标为「说话人 N」，不能区分时字幕不加前缀、正文标为「说话人」。已有记录中的标签保留。

「实时转写」默认开启。浮条在同一个面板中显示字幕和录音控制，灰字为尚未确定的文字；字幕开启时浮条保持展开，鼠标移入只显现拖动提示。关闭字幕后恢复紧凑浮条，鼠标移入展开拖动区。会议转写页约每 10 秒保存一批确定句子。网络故障不影响本机录音。

「结束后自动补齐缺口」默认开启，只识别实时转写缺失的时段。关闭实时转写时不会自动识别整段。手动点击「识别整段／重新识别整段」处理当前选中录音的完整内容，成功后替换该段转写；有现有文字时先确认覆盖，人工修改过的文字会明确提示。

录音选择区常显编号、起止时间、时长和识别状态，选中段标有「当前选中」。回听条显示当前录音段，转写阅读区继续保留全部录音段的内容。

处理进度按实际工作显示准备、上传、提交、等待结果、保存文字和清理临时录音。插件现场采集的 WAV 只有超过服务文件大小或时长上限时才拆分；分段后保留原时间轴，并说明说话人编号重新开始。原录音不压缩、不修改。

关闭思源或断网后，本机保留已提交的任务和已取得的结果。重开对应会议查询原任务，不自动再次提交。尚未提交完的部分可点击「继续原任务」。提交响应丢失时会明确显示结果不确定，避免无意重复计费。保存期间中断或文字发生修改时保留原有文字，按提示检查；可放弃本次结果后重新识别。

识别费用、重复整段识别费用和 COS 存储及流量费用统一在设置页说明。继续查询已提交任务、重试云端清理不会新建识别任务。失败日志只保留脱敏诊断字段，不包含密钥、音频或转写正文。

## 整理纪要

先在思源设置中配置 AI 模型，再手动点击“生成纪要”。生成前会列出尚未转写、缺口未补齐的录音；也可只使用笔记或选择部分录音。已有纪要时，这些选项收在纪要上方的「材料范围」中，有未完整的转写时旁边显示一个小圆点。保存成功不再单独提示，纪要内容出现即表示已保存。

纪要页可选择「通用纪要 / 行动清单 / 决策记录」。点击旁边的「管理模板」，可以新建自定义模板，或复制内置模板后修改；设置中的「管理纪要模板」打开同一个管理界面。

自定义模板由名称、提示词和 Markdown 模板组成：提示词描述整理重点和要求，Markdown 模板定义标题、表格等输出结构。提示词与 Markdown 模板至少填写一项；其中的示例不当作会议事实，也不执行代码或变量表达式。模板保存到当前工作空间的插件数据中。删除模板会保留已有纪要，使用它的会议需重新选择模板后才能生成。

选择或修改模板不会调用 AI。模板、笔记或纳入范围的转写有变化时，纪要生成信息后会附上一句更新提示；点击「重新生成」后才应用。恢复原内容后提示消失；以前生成且没有材料记录的纪要不会凭空提示过时。

每次开始生成时会从思源读取当前 AI 配置，并固定用于本次请求；不沿用会议页打开时的旧配置。鉴权失败、模型不可用、服务拒绝、额度不足等情况分别说明，并保留不含密钥或会议正文的本机诊断日志。

生成使用点击时确认的材料，不随之后的编辑变化。配置了模型容量时会预先检查，超出则提示缩小范围；未填写容量也可正常生成。AI 服务无法处理时会提示失败，不会悄悄删去部分内容。

每场会议只保留一份纪要。“重新生成”须确认，并覆盖同一份纪要；修改过的纪要会明确提醒修改将丢失。如果生成期间又修改了纪要，插件会保留修改并提示检查。生成可以取消，失败后可手动重试。

如果生成成功但保存失败，本页会保留生成结果，可「重试保存」或「复制生成结果」。重试保存不会再次调用 AI，也不会重复追加已经保存的内容；原纪要在此期间被修改时，先检查文档并保留需要的结果。关闭会议页前，请先保存或复制本次尚未保存的结果。

AI 结果需要人工核对。缺失的负责人、期限和决定应保持未知；笔记与转写有分歧时应保留差异。

## 保存与同步

完成的音频、笔记、转写和纪要沿用思源的同步方式。音频关联在转写文档中；停用插件后，原生文档仍可阅读。正在进行的录音由当前设备管理，不能换一台设备继续同一段录音。其他设备同步后可以回听，波形预览仅保存在录制设备上。

同步完成后，已打开的会议页会刷新转写、录音状态和纪要；刷新原生编辑器前先保存尚未提交的编辑。也可从会议页的更多菜单选择「重新加载会议数据」。查看同步过来的内容不需要重新转写或生成纪要。

## 当前验证范围

导入、会议目录、双向导航与手机简版已通过 60 项本地测试、语法检查和构建。非浏览器模拟交互检查覆盖三个只读标签切换、阅读位置保留、播放不中断与关闭清理；手机实际视觉和触摸体验仍待实机确认。已用 macOS 原生工具生成的 AAC／ALAC M4A 验证容器时长读取，并在仅提供思源 API、禁止 Node/Electron 的环境完成移动端加载与卸载检查。模拟服务覆盖 M4A 原文件提交、格式参数及中断后恢复。以上不等同于 iPhone 实机验收：苹果语音备忘录实际导出文件的选择、附件上传、设备回听与云端识别尚待验证；未运行浏览器或截图检查。

当前 COS 与标准录音识别接入已通过本地语法、构建及模拟服务检查，覆盖单声道混音、任务恢复和保存后清理。此前的真实云端验证属于旧接口，不能作为本次标准版接入的验证。当前真实 COS 上传、两家标准版计费识别、安装与界面效果尚待验证。

Windows 与 macOS 都需分别在实机验收双方声音、暂停续录、浮条焦点与全屏多屏、设备断开、两小时录音和跨设备回听。已有 Windows 短录采集确认；macOS 的包兼容性、宿主权限声明和浮条配置已核对，真实采集与完整设备流程尚待验收。录音到真实实时转写的完整设备流程，以及真实 AI 生成尚未验收。
